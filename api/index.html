1. 初始支持集与独立验证集

可多选图片，或点击“选择文件夹”批量读取文件夹及子文件夹中的图片。分别选择对应的 normal / defect 文件夹，选择后再点击登记按钮；请勿选择包含全部实验分组的目录。初始支持集需要正常 100 张、缺陷 30 张。

验证图片不参与训练，首次验证后固定。默认两类各至少 5 张。

先创建任务并登记图片；仅选择文件或文件夹还没有完成上传登记。
